# Java 核心知识学习路线

本文连接已有的 11 组原理篇与面试篇。阅读目标是能解释状态变化、画出对象和等待关系、构造反例，再讨论方案的适用边界。

## 先修关系与学习顺序

1. 集合与泛型：先确定对象相等、顺序、所有权和类型约束。
2. 类加载、注解、反射与代理：从声明元数据追到运行时对象与实际调用。
3. 锁、JUC 与线程池：从共享不变量追到等待、完成和执行资源。
4. IO 与 JDBC：把协议状态、缓冲和连接事务放入前面的生命周期模型。

## 怎样检查自己是否真正理解

| 能力 | 练习方式 | 达标依据 |
|---|---|---|
| 正常执行 | 给状态和对象逐步编号 | 能解释每步依赖的前提 |
| 竞争路径 | 把两个线程交错在每个非原子步骤之间 | 找到真正的生效点和重新检查点 |
| 失败路径 | 在创建、等待、执行、提交、关闭处分别注入失败 | 每个结果终态和资源归属清楚 |
| 内存与类型 | 画强弱引用、定义加载器与泛型声明关系 | 不把同名、浅复制、弱键当完整证明 |
| 方案比较 | 在同一负载与语义约束下比较 | 能说出获得的能力和付出的成本 |

## 三条贯穿所有主题的案例

**请求处理链**：代理接纳调用 → 线程池排队 → 连接获取 → SQL 执行 → 事务提交 → 网络响应。逐段问超时预算、上下文归属、异常包装和取消后是否仍有副作用。

**插件替换链**：新加载器定义类型 → 解析注解与泛型 → 创建反射计划和代理 → 注册任务 → 停止旧任务并注销缓存。逐段问类型身份、模块访问和旧加载器被谁保留。

**并发数据链**：构造不可变消息 → 安全发布或入队 → 消费者领取 → 修改业务状态 → 返回完成结果。逐段问可见性、原子性、所有权与完成确认是否各有协议。

## 版本与验证边界

规范说明可依赖的语义，指定源码标签说明那一版的实现。文档以已有的 JDK（Java Development Kit，Java 开发工具包）版本对照为基础；不要把内部字段、阈值与某版生成代码当永久接口。

可运行小例子用于固定某种观察场景；伪代码用于解释协议，不能直接视为生产实现。真实数据库提交断线、驱动游标、文件系统持久化及硬件性能仍需在相应环境验证。源码阅读、正确性推理和性能测量是互补证据。
